OpenAI, GPT-6.2 Astra·Sol 출시…Astra API 20% 인하

Introducing GPT-6.2 Astra and Sol

OpenAI가 고난도 연구·코딩용 프리미엄 모델 GPT-6.2 Astra와 일상 업무용 저가 모델 GPT-6.2 Sol을 ChatGPT Work·Codex와 API에 공개함. Astra API 가격은 이전 세대보다 20% 낮은 입력 100만 토큰당 $8, 출력 $40이며, Sol은 $2/$10으로 동결됨.

  • Astra API $8/$40(입력/출력, 100만 토큰), 이전 대비 20% 인하
  • Sol은 $2/$10 동결, FrontierCode 2.0서 Astra와 0.5점 차
  • Astra, 대비 프레임워크상 자기개선 'High' 도달한 첫 공개 모델

💡 왜 중요? 프런티어급 성능이 빠르게 싸지면서 '거의 같은 성능의 저가 모델'(Sol)이 실무 기본값이 되는 흐름임. 동시에 사이버·자기개선 위험 등급이 올라가 안전장치 논쟁도 커지고 있음.
